# Display Core

تطبيق بسيط لإعدادات الشاشة على X11 باستخدام `C` و `GTK3` و `XRandR`.

## الميزات الحالية

- عرض الشاشات المتصلة
- تفعيل أو تعطيل كل شاشة
- اختيار الدقة ومعدل التحديث إن توفر أكثر من وضع
- تغيير اتجاه الشاشة
- تحديد الشاشة الأساسية
- تحديث الحالة الحالية من الخادم
- معاينة بصرية لترتيب الشاشات مع السحب بالفأرة
- حفظ واسترجاع بروفايلات الشاشات
- أوضاع سريعة مثل `Extend` و`Mirror`
- تراجع آمن بعد التطبيق إذا لم يتم تأكيد الإعدادات

## المتطلبات

- `gtk+-3.0`
- `xrandr`
- خادم `X11`

## البناء

```bash
make
```

## التشغيل

```bash
./display-settings
```

## ملاحظات

- التطبيق مخصص لـ `X11` فقط، وليس لـ `Wayland`.
- يعتمد على مكتبة `XRandR` مباشرة.
- يمكن ترتيب الشاشات عبر السحب داخل المعاينة أو يدويًا عبر حقول `X` و `Y`.
- في بعض الإعدادات المعقدة جدًا مثل مشاركة `CRTC` بين أكثر من مخرج قد تحتاج لاحقًا إلى منطق أوسع.

## هيكل المشروع

```text
src/
  app/       ربط التطبيق وتنسيق التدفق العام
  domain/    النماذج والتحويلات العامة
  services/  خدمات النظام والتعامل مع XRandR
  ui/        مكونات الواجهة
```
